# Physics-Constrained Rectified Flow for Climate Downscaling

Arun Sharma, University of Minnesota, Twin Cities.

This repository holds the 9-page manuscript prepared for the AIAS+ 2026 proceedings, together with the LaTeX source that builds it.

The PDF is `PCRF_AIAS2026_camera_ready.pdf`.

## Build

```bash
./build.sh
```

That writes `main.pdf`. The class and the ACM reference style are included, so the build does not depend on a particular TeX Live install beyond a standard pdfTeX and BibTeX.

## Status

The DOI, ISBN, and license line printed on the PDF are placeholders. The ACM rights form has not been returned yet. Replace the rights block in `main.tex` with the lines that form returns before the proceedings upload.
